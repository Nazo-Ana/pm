# Project Management MVP

Local Kanban workspace with dummy authentication, SQLite persistence, and an OpenRouter-powered board assistant.

## Run

Add `OPENROUTER_API_KEY` to `.env`, then run `scripts/start.ps1` on Windows or `./scripts/start.sh` on macOS/Linux. Open http://localhost:8000 and sign in with `user` / `password`.

Stop with the matching stop script.
